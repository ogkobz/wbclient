# wbclient

[![tests](https://github.com/ogkobz/wbclient/actions/workflows/tests.yml/badge.svg)](https://github.com/ogkobz/wbclient/actions/workflows/tests.yml)

Клиент Wildberries Seller API на Python: карта доменов, разбор токена, соблюдение лимитов и понятные ошибки.

Библиотека закрывает ту часть работы с API, которую иначе каждый раз пишешь заново, и не лезет в бизнес-логику — она у каждого продавца своя.

## Зачем

В документации WB есть три вещи, о которые спотыкаешься, пока не наступишь:

**У WB не один адрес, а четырнадцать.** У каждой категории методов свой хост: контент — на `content-api`, цены — на `discounts-prices-api`, статистика — на `statistics-api`. Промахнулся хостом — получил 404.

**Ошибка 4XX списывается из лимита как десять запросов.** Поток опечаток в параметрах выжигает бюджет в десять раз быстрее, чем считаешь по числу вызовов. Поэтому дешевле отказать локально, чем отправить заведомо провальный запрос.

**Токен — это JWT, в котором записаны права.** В поле `s` лежит битовая маска категорий, в бите 30 — признак «только чтение», в `acc` — тип токена. Всё это читается до первого обращения к сети, без подписи и без запроса.

Клиент опирается на эти три факта: выбирает домен по категории, проверяет права заранее и держит паузы по заголовкам ответа, а не по догадкам.

## Установка

```bash
pip install -e .
```

Зависимость одна — `requests`. Ядро от неё не зависит: сетевой слой подменяемый.

## Использование

```python
from wbclient import WBClient

client = WBClient("ваш.jwt.токен")

# Что умеет токен — видно до первого запроса
print(client.info.token_type)      # basic / test / personal / service
print(sorted(client.info.categories))  # ['content', 'prices']
print(client.info.read_only)       # False
print(client.info.seconds_left)    # сколько секунд до истечения

# Запрос: первым аргументом — категория, вторым — путь
cards = client.post(
    "content",
    "/content/v2/get/cards/list",
    json={"settings": {"cursor": {"limit": 100}, "filter": {"withPhoto": -1}}},
)

orders = client.get("statistics", "/api/v1/supplier/orders", params={"dateFrom": "2026-01-01"})
```

Домен подставляется сам. Тестовый токен (`acc = 2`) автоматически уводит запросы в песочницу; если у категории песочницы нет, клиент скажет об этом словами, а не 404-м.

## Обработка ошибок

Тип исключения отвечает на вопрос «имеет ли смысл повторить»:

```python
from wbclient import WBForbiddenError, WBRateLimitError, WBValidationError

try:
    client.post("prices", "/api/v2/upload/task", json=payload)
except WBForbiddenError as exc:
    ...  # нет нужной категории у токена или токен только на чтение
except WBValidationError as exc:
    ...  # запрос не пройдёт и со второй попытки: exc.detail скажет почему
except WBRateLimitError as exc:
    ...  # лимит, повторить через exc.retry_after секунд
```

Повторы по `429` и `5XX` клиент делает сам: по `429` — ровно столько, сколько сказал сервер в `X-Ratelimit-Retry`, по `5XX` — с экспоненциальной задержкой 1, 2, 4 секунды. Остальные коды поднимаются сразу: повторять их бессмысленно, а стоят они десять единиц лимита каждый.

## Что внутри

| Модуль | Отвечает за |
| --- | --- |
| `endpoints.py` | Карта из 14 доменов, тестовые хосты, соответствие «сервис — категория токена» |
| `token.py` | Разбор JWT без проверки подписи: категории, тип, срок, признак «только чтение» |
| `ratelimit.py` | Token bucket на каждый домен, состояние из заголовков ответа, потокобезопасность |
| `errors.py` | Иерархия исключений по кодам и разделение на повторяемые и нет |
| `client.py` | Сборка: маршрут, проверка прав, паузы, повторы |

## Тесты

```bash
python -m pytest
```

90 тестов, ни один не ходит в сеть: транспорт и часы внедряются через параметры, поэтому проверка ретраев по `5XX` занимает миллисекунды вместо семи секунд ожидания.

Честная оговорка: тесты идут на моках по документации. Против живого кабинета продавца библиотека не проверялась — для регистрации на WB нужен гарантийный взнос.

## Границы

Библиотека не оборачивает методы по одному: их сотни, они меняются, а обёртка над каждым устаревает быстрее, чем пишется. Путь передаётся строкой из документации — так метод, появившийся вчера, работает без обновления библиотеки.

Асинхронного клиента пока нет. Точка расширения под него уже есть: `Transport` — это протокол, ядро на `requests` не завязано.
